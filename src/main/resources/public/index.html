팀 강점 (Our Strengths)

검증된 팀워크와 협업 능력

저희 팀은 삼성 청년SW·AI아카데미(SSAFY)에서 만나, 신한은행 해커톤을 통해 협업 능력을 검증받으며 탄탄한 팀워크를 다져왔습니다.

다양한 분야의 전문성

백엔드, 프론트엔드, 모바일(Android) 개발뿐만 아니라 기획, 운영, 연구, 창업 등 다양한 경험을 보유하고 있어, 아이디어 구상부터 실제 서비스 구현·운영까지 전 과정을 수행할 수 있는 역량을 갖추고 있습니다.

광범위한 기술 스택 및 전 주기 개발 경험

Android, iOS, 백엔드(Spring, Kotlin, Java), 프론트엔드(React, TypeScript), DB(MySQL, PostgreSQL, Firebase) 등 폭넓은 기술 스택을 보유하고 있습니다.

인턴십 및 해커톤을 통한 요구사항 분석 → 설계 → 구현 → 테스트 → 배포 → 운영까지의 전 주기 경험과 Git 기반 협업, CI/CD 환경 구축 경험으로 효율적이고 확장 가능한 개발이 가능합니다.

실전 문제 해결 능력

금융 API, 인증·보안 처리, AI 서버 연동, DB 설계 등 다양한 실전 문제 해결 경험을 보유하고 있습니다. 해커톤 프로젝트에서 단기간 내 프로토타입을 구현하고 수상 경험을 통해 신속한 문제 해결과 실행력을 검증받았습니다.

창의적 기획력과 사회적 가치 지향성

업사이클링 관련 창업 경험을 포함한 3회의 창업 활동을 통해 단순한 기술 구현을 넘어, 지속가능성과 사회적 임팩트를 실현하는 프로젝트에 최적화된 팀입니다.
