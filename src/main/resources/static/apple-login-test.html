Apple OAuth2 로그인 테스트 페이지

1. Apple 로그인 페이지 열기

아래 입력값을 이용해 https://appleid.apple.com/auth/authorize URL을 생성합니다. 애플 개발자 콘솔에 등록한 서비스 식별자(클라이언트 ID)와 동일한 값을 사용해야 하며 response_type은 code id_token 조합을 권장합니다.

백엔드에 등록된 리다이렉트 URI와 반드시 일치해야 합니다.

id_token을 함께 반환받아야 서버에서 검증이 가능합니다.

form_post 모드를 사용하면 code/id_token이 POST 바디로 전달됩니다.
